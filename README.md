# Cosatore: release

Questo repository contiene solo gli installer di Cosatore, pubblicati nelle
[release](../../releases). Il codice sorgente non è qui.

| File                                   | Cosa installa                         |
|----------------------------------------|---------------------------------------|
| `Cosatore-server-windows-<versione>`   | Server per Windows                    |
| `Cosatore-server-ubuntu-<versione>`    | Server per Ubuntu                     |
| `Cosatore-client-windows-<versione>`   | Finestra desktop per Windows          |
| `Cosatore-client-ubuntu-<versione>`    | Finestra desktop per Ubuntu (`.deb`)  |

L'installazione del server richiede una licenza valida: l'indirizzo per ottenerla viene fornito insieme al contratto.
